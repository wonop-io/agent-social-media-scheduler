Portable Agent Social Media Scheduler skill for Claude and OpenAI hosts.

- Chrome-extension workflow with one native scheduled wake-up per video item.
- Self-contained posting briefs, timezone handling, duplicate checks and first-comment follow-ups.
- Installation and usage instructions, MIT license and Wonop beta CTA.
- 60-second Pages Printer card demo, edited with HyperFrames from the supplied Wonop livestream.

Install the skill from `skills/agent-social-media-scheduler/` or the release ZIP. Browser and scheduler capabilities must both be available in the chosen host; live unattended social publishing has not been tested as part of this release.
